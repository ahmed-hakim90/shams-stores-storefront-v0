## الحالة الفعلية

هذا مستودع Next.js App Router لواجهة المتجر، وليس قالب WordPress. يستخدم React 19 وTailwind 4 وTanStack Query وBase UI. راجع package.json للإصدارات الدقيقة؛ مدير الحزم المثبت فيه pnpm 12.3.4.

وقت التسليم كان الفرع main عند 7d6381d، مع تعديلات كثيرة غير ملتزم بها وملفات جديدة. هذه لقطة تاريخية: افحص Git من جديد، ولا تعتبر التعديلات منشورة. بعض التعديلات تخص المالك، ومنها خلفيات حقول الدفع البيضاء وتغييرات التنقل؛ لا ترجعها تلقائيًا.

المنفذ: إثراء المنتجات بالضمان والوكيل، إكسسوارات من محرك التوافق، خيارات العدسات والكِت، محتوى الحملات والفروع وصفحات المحتوى، SEO overrides، تقييمات فعلية، فصل مسار مفضلة العميل، وتحسين التحقق من الدفع والهوفر والتركيز بالمفاتيح. التفاصيل والحدود في تقرير التنفيذ.

تم نشر الواجهة في 19 سبتمبر؛ لم يتم تثبيت/تفعيل حزمة WordPress الجديدة. وجود endpoint حي لا يثبت أن كل حزمة محلية مثبتة.

## قرارات المالك التي يجب الحفاظ عليها

- الهاتف **إجباري**؛ هذا هو التأكيد الأحدث، ويتجاوز الرسالة الأقدم التي قالت إنه اختياري.
- الحقول الناقصة لا تعطل زر التأكيد مسبقًا. الضغط يوضح الأخطاء ويركز أول حقل؛ منع تكرار الإرسال أثناء الطلب الفعلي أو النتيجة غير المؤكدة يظل ضروريًا.
- لا تعديل تلقائي لفورم WordPress بواسطة Commerce UX. المطلوب الاعتماد على إعدادات WordPress؛ الواجهة الحالية لا ترث schema الحقول بعد، فلا تدّعِ اكتمال ذلك.
- «كل البلاجن» يعني إضافات شمس المخصصة؛ ظهور بياناتها في API لا يعني عرض شاشات الإدارة للعميل أو نسخ CSS القالب.
- لا اختراع اسم وكيل، مدة ضمان، خصم، شحن مجاني أو سياسة إرجاع. اعرض البيانات المعتمدة فقط، وأخفِ الشارات غير المفعلة.
- حافظ على الشعار وهوية شمس البرتقالية والتوكنز الحالية. لا تبدأ إعادة تصميم شاملة دون طلب.

## الضمان والوكيل — تعديل محلي 19 سبتمبر
طلب المالك عرض النص الخاص المتعبّي دون اشتراط checkbox. تم تحديث ProductAssurances والبحث السريع مع fallback warranty_text؛ مصدر custom_label يتطلب Commerce UX 0.8.2 من مستودع WordPress. لم يتم نشر هذا التعديل أو تثبيت البلاجن بعد. اختبارات الواجهة 58، TypeScript ناجح؛ معاينة المكوّن ببيانات اختبار عربية داخل RTL وLTR عند 390/768/1024/1440 دون overflow؛ ليست تحققًا من بيانات الإنتاج.


## حسابات التحويل — 0.8.3
جاهزة من إعدادات Woo BACS، وتظهر عند اختيار bacs مع أزرار النسخ. مطلوب تثبيت Commerce UX 0.8.3 بدل 0.8.2 لتوفير bank_transfer؛ بدونها تظهر رسالة عدم توفر التفاصيل. لا حسابات مثبتة في الواجهة. اختبارات الواجهة 61 وWordPress 97 وTypeScript وPHP syntax ناجحة. معاينة بيانات اختبار على أربع مقاسات دون overflow؛ لم يتم تحويل أموال. إصلاح shipping_lines.instance_id نُشر، لكن قفل المحاولة القديمة يحتاج مراجعة تشغيلية ولا يُحذف تلقائيًا.
