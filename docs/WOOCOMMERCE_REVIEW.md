# مراجعة التجهيز للاتصال بـ WooCommerce

## النتيجة

تم تجهيز كتالوج متصل قابل للتفعيل من إعدادات البيئة، مع إبقاء الوضع الافتراضي تجريبيًا. المشروع ليس جاهزًا بعد لاستقبال طلبات ودفع حقيقيين.

## ما تم إصلاحه وتجهيزه

- اتصال REST API من السيرفر فقط، بمفاتيح خاصة وHTTPS ومهلة انتظار وأخطاء لا تكشف ردود الخدمة الداخلية.
- جلب المنتجات وصفحة المنتج والبحث والتصفح المتتابع مع الاحتفاظ بمرشحات التصنيف والعلامة والترتيب.
- منع الرجوع للمنتجات التجريبية عند فشل الاتصال.
- إصلاح تسجيل المنتجات في السلة بسعر صفر، وتمرير الكمية المختارة، وتجميع المنتج المتكرر وإتاحة حذفه.
- فصل السلة المحلية التجريبية عن سلة WooCommerce، وتصحيح تنسيق إجمالي درج السلة.
- منع إضافة المنتجات التي تحتاج خيارات غير مدعومة، وتصحيح التحقق من مكونات الباقة المفقودة.
- تعطيل الدفع الوهمي وحجب صفحات الطلبات والحسابات والباقات التجريبية في وضع WooCommerce.
- واجهة بحث وسلة مبسطة لوضع الكتالوج المتصل؛ التصميم الكامل الحالي محفوظ في الوضع التجريبي.

## التحقق

- نجحت 8 اختبارات لوحدة WooCommerce باستخدام استجابات محاكاة: الإعدادات، التصفح، التحويل، الأخطاء وعدم تسريب المفاتيح.
- نجح TypeScript وبناء الإنتاج للوضع التجريبي ووضع WooCommerce.
- API المحلي أعاد منتجات التجربة ورفض قيم التصفح غير الصالحة برمز 400.
- وضع WooCommerce دون إعدادات أعاد 503 برسالة آمنة، وأظهر صفحة خطأ قابلة لإعادة المحاولة. لم يتم الرجوع للبيانات التجريبية.
- تم التحقق من عدم عرض رقم الطلب التجريبي في مسارات الحساب والنجاح، ومن حالات عدم العثور لصفحات المقارنة والباقات غير المربوطة. يستخدم Next.js استجابات متدفقة قد تحمل HTTP 200 مع حالة عدم العثور داخل الصفحة.
- اختبار المتصفح: إضافة وحدتين من منتج سعره 129,900 سجلت الكمية 2 وأظهرت إجمالي 259,800 في السلة بعد الانتقال.
- فحص السلة عند عرضي 375 و390، وواجهة خطأ الاتصال عند 430 و1024 و1440 لم يجد تجاوزًا أفقيًا. تمت معاينة شاشة المنتج على الموبايل. هذا فحص محدود، وليس اختبار قبول كامل لكل الصفحات.
- فحص الاتصال الحقيقي لم ينجح لأن الإعدادات المحلية ليست إعدادات WooCommerce صالحة؛ لم يتم إنشاء طلبات أو تنفيذ مدفوعات أو تعديل المتجر.

## المطلوب للتفعيل

إضافة رابط متجر WooCommerce ومفتاح قراءة فقط وسره داخل `.env.local` أو إعدادات النشر، والتحقق من أن عملة المتجر EGP. ثم تشغيل `pnpm commerce:check`. عند نجاحه يمكن تفعيل `COMMERCE_PROVIDER=woocommerce` وإعادة التشغيل أو البناء.

قبل الإطلاق التجاري يلزم ربط جلسة السلة والخادم المرجعي للأسعار والمخزون والشحن والضرائب والدفع، ثم الحسابات والطلبات، واختيارات المنتجات والباقات وبيانات الواجهة الرئيسية. التفاصيل والخطوات في [دليل الإعداد](../ENV_SETUP.md).
